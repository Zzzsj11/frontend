当前 Web 内测版已经在 ASS 分镜和通用分镜表单中保留图片/视频模型选择器，但可用模型暂时只有：

- 图片模型：`Img2`（API 值：`gpt-image-2`）
- 视频模型：`sd2.0`（API 值：`doubao-seedance-2.0`）

因此两个模型选择器当前为必选但禁用状态。后续 Agent 在确认有新模型可以正式接入时，必须完成以下工作，不能只在前端增加一个下拉选项。

## 推荐后续设计

模型达到两个以上时，建议新增后端模型能力接口，例如 `GET /api/generation-models`，由后端返回可用模型及能力矩阵。前端不应长期硬编码供应商能力。建议响应至少包含：

```json
{
  "kind": "video",
  "id": "provider-model-id",
  "label": "用户可读名称",
  "enabled": true,
  "ratios": ["16:9", "9:16"],
  "resolutions": ["720p", "1080p"],
  "duration": { "min": 4, "max": 15, "step": 1 },
  "referenceImage": { "min": 0, "max": 1 }
}
```

模型能力应由后端配置或数据库管理，前端只负责呈现和提交；任务创建时应保存一份能力快照，避免模型配置变化后无法解释历史生成参数。
