## 验证范围

后端定向测试覆盖认证、错误与请求日志、多用户、用户旅程、归档、媒体格式、渠道偏好和新增边界。导出样例在本机执行真实 FFmpeg，生成请求使用模拟响应。浏览器权限与导出流程使用 Playwright 的本地 mock。独占 PostgreSQL 的并发验收已通过。实际可信代理的客户端地址还需在对应环境核验。

项目目录分页另以 `tests/user/domainApi.test.ts` 校验跨页重叠时按 ID 去重，并在旧后端忽略 offset、整页重复时结束。本文件 5 项测试通过。

## PostgreSQL 并发和迁移演练

运行 `backend/.venv/bin/python scripts/local_api_concurrency_proof.py` 会创建独占临时 PostgreSQL，结束后清理本次容器与网络。2026-11-19 验收通过。

- OPS-02 使用含 `@` 的合成数据库角色及含 `:%@/?#` 的口令从空库执行 Alembic 至 head，验明版本记录存在，并检查迁移输出未出现原始或 URL 编码口令。
- API-02 验证两种交错顺序。在签发凭证前暂留事务，通过独立连接看到另一请求等待 PostgreSQL 行锁后继续。先登录时，刚取得的旧凭证在改密后失效，refresh 也被拒绝。先改密时，等待中的旧密码登录被拒绝。两种顺序最终均只有改密产生的会话有效。
- API-04 通过 ASGI 入口同时打开聊天、工单、大纲、素材导出 4 类 SSE，每类 2 路，在首个事件的网络发送处保持等待。池配置为 2 个连接、零溢出，8 路订阅同时打开时 6 次真实鉴权和数据库读取均成功。聊天和工单入口也在另开会话检查资源前归还鉴权连接。
