## P2 核验与处置

### 后端

- 网关标记存在但配置缺失时直接拒绝恢复，避免提交窗口改走直连。
- 内容违规及取消不计图片全站可用性熔断；优化器结构性空返回不计可用性故障，系统指令为独立 system 消息。
- 供应商筛选在 SQL 领取前执行，避免前 100 条形成饥饿。
- ffprobe/ffmpeg 设置超时并回收子进程；上传/探测及首帧解析限制 file/pipe 协议，防止伪装媒体中的网络引用绕过下载校验。
- 五类历史视频轮询共用超时/重试迭代器，保留各协议终态与结算差异；HappyHorse/Wan 共用查询实现。
- 删除退役资产补注册函数，所有环境继续禁止恢复旧 cron/launchd。
- 素材导出用户级锁、工单与导出记录原子落库；视频批次工单和日配额同事务，全部成功后才派发，任一项失败整批回滚。
- refresh token 增加 family 与重用撤销；5 秒并发刷新缓冲后重用旧凭证会撤销该 family 及旧 access token。
- 普通用户模型查询不返回 Key 尾号；聊天异常脱敏并统一 UTC。
- 图片上传原本已解码校验；补充音视频实际容器/流校验，避免只信任 MIME。
- 三类资产补 generation_job_id/is_current 索引。
- 普通用户鉴权原本只有 1 次用户查询；原评审“每请求 3 次”不准确。管理员原有 3 次，现在合并角色/权限查询为 2 次，并排除已软删除角色的权限。

### 前端

- 逐句提示词等待携带任务 signal，切任务取消；同 jobId 多个订阅分别保存，互不覆盖。
- 后台标签降低轮询频率，回到前台立即同步。
- 人物待恢复草稿按用户隔离，登出清理；异步余额结果也验证当前账号。
- 同一 ApiError 只上报一次；两处余额校验复用 auth store，合并并发请求。
- 脚本缓存保留约 20 个最近任务；SSE 畸形/空事件不会中断后续有效事件。
- 历史样式色值集中到精确色板，避免在局部深色主题下改变原硬编码颜色含义；补缺失语义令牌，统一 z-index 令牌和文档。
- 修正文档默认插槽、并发注释；远程 E2E 必须显式指定目标，0 不视为开启，避免移除公网默认值后反而静默命中本机。

### 运维与文档

- 开发数据库仅绑定回环，密码/账号可配置；生产继续使用 Secret；去除默认公网目标和 CORS 公网 IP。
- 前后端构建上下文排除 runtime secret、数据库密码、数据库及验收产物；移除 Python 3.14 死代码，补 API 排空时间。
- setup 创建 venv，stop 包含 workers；inline 发布停止旧 Worker，不再显式拉起 Worker 服务。
- 部署模板将无效 MEDIA_WORKER_CONCURRENCY 替换为 IMAGE/VIDEO_WORKER_CONCURRENCY；更新 Python/端口、退役调度、Docker 用法及实际门禁耗时。
- 历史截图为审计证据，保留原文件；本轮不新增任何媒体或构建产物入库。“34 张 PNG”的数量与当前 Git 跟踪集合不符，不以删除历史证据假装减小 Git 历史体积。

TLS 部署会检查证书信任链、域名和私钥匹配，解引用证书符号链接，并保存成功部署的 TLS 配置供后续发布/回滚复用。实际证书和生产 HTTPS 仍待验收。
