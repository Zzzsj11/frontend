P2GW-06源码审查

网关在鉴权前整包复制每个请求体

默认单请求允许 32 MiB。中间件先积累 bytearray，再转成 bytes。这两份数据至少在转换期间并存，下游解析还需要额外内存。公开 API 容器默认内存 768 MiB，并发时即使每个请求都未超单体限制也可能耗尽内存。

修复与验证 在边界按流计数，避免保留两份完整副本。媒体使用限额临时文件。测量多连接下的 RSS 和被拒请求的读取量。
