# 线上验收检查表

> 适用场景：域名、HTTPS、容器、数据库、Redis、后端接口和前端页面全部部署完成后，用这份清单逐项确认是否可以正式进入线上验收。

## 一、域名与 HTTPS

- [ ] `mv.yangxiaren.club` 可以正常解析到服务器公网 IP。
- [ ] `https://mv.yangxiaren.club` 可以正常打开。
- [ ] `http://mv.yangxiaren.club` 会自动跳转到 HTTPS。
- [ ] 证书签发成功且证书路径正确。
- [ ] Certbot 自动续期任务已启用。
- [ ] Nginx 配置已切换为域名模式，不再使用通配 `server_name _` 作为最终生产配置。

## 二、容器与编排

- [ ] `docker compose up -d --build` 可以成功完成。
- [ ] `frontend`、`backend`、`postgres`、`redis` 四个服务都处于正常状态。
- [ ] 后端健康检查 `/api/health` 返回 200。
- [ ] 前端首页可以通过域名访问。
- [ ] 站点访问过程中没有持续性的 502 / 503 / 504。

- [ ] 数据库迁移在容器启动时可以自动执行。

- [ ] 可以通过 SSH 隧道连接 PostgreSQL。
- [ ] 可以通过 SSH 隧道连接 Redis。
- [ ] 如需公网开放端口，已完成 IP 白名单限制。
