## 发布范围与回退

通用 MV 大纲默认使用 `gpt-6-astra`；`GENERAL_OUTLINE_LLM_MODEL` 可显式覆盖为旧模型。ASS、逐镜提示词、聊天等继续使用各自既有配置，避免把大纲验证结果推广到未测试的调用链。

- 请求参数按模型适配，逐次记录实际模型与 token 用量。
- TLS、连接异常、超时、429/5xx 和繁忙文本最多自动重试两次，有退避。
- 通用大纲最多两轮结构修正，网络重试与结构修正共享五次调用上限。
- 顶层字段、总数与类型配额分别诊断；把顶层输出契约明确加入系统消息。
- 页面刷新和任务切换正确恢复/清除大纲进度与失败原因。
