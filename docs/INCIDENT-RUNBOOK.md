# 故障处置手册

先确认影响范围并冻结发布；执行 `scripts/online-health-check.sh`；检查容器状态、后端错误日志、磁盘、数据库连接、Redis 和供应商健康；记录 Request ID、任务 ID、版本标签和时间线。

应用故障优先回滚旧镜像。数据故障先停止写入并保全备份。供应商故障停用后台模型或切换路由。恢复后复跑远程测试，补充根因、影响、修复和预防措施，不能只清除错误日志。
